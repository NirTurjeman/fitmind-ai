# FitMind AI — landing page

A single-file, responsive static landing page for an early-stage wearable-data conversational AI concept.

## Deploy on Vercel

1. Create a new GitHub repository and upload `index.html` to its root.
2. In Vercel, select **Add New → Project**, import the repository, and deploy it as a static/Other project. No build command is needed; the output is the repository root.
3. Open the real deployed URL and confirm it works before submitting it to OpenAI.

Alternatively, use GitHub Pages by enabling Pages for the repository's main branch and root folder.

## Notes

- All health numbers shown are fictional examples.
- The site intentionally makes no claim that Fitbit or OpenAI integrations are already approved or implemented.
- No tracking, forms, analytics, or user health data collection is included.
- Before collecting health data, implement and publish a complete privacy policy and consent process.
